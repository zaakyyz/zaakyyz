# Profile maintenance

Edit `README.md` to change the introduction, technologies, or project spotlight.
The custom header lives in `assets/banner.svg`.

Statistics are generated by `scripts/update_stats.py` using Python 3's standard
library and GitHub's API. They are stored in this repository, so the profile
does not depend on a third-party statistics-card server.

The workflow runs daily at 01:23 UTC (08:23 WIB), when its source changes, or
manually from **Actions → Update profile statistics → Run workflow**. GitHub
may delay scheduled runs and disables scheduled workflows in public repositories
after 60 days without repository activity. Re-enable the workflow if necessary.

The workflow uses the built-in `GITHUB_TOKEN`; no personal access token or extra
secret is required. For a local refresh, authenticate with `gh auth login` and
run `python scripts/update_stats.py`, or supply `GH_TOKEN` in the environment.

Repository counts, stars, and language shares include only owned public,
non-fork repositories, excluding this profile repository. Language shares use
GitHub's language byte counts, include notebooks, and do not indicate skill level.
Contributions use the visible GitHub contribution calendar for the last year.
Badges and technology icons use Shields.io and skillicons.dev.
