# Profile maintenance

Edit `README.md` to change the introduction or technologies.
The custom header lives in `assets/banner.svg`.

The contribution card is generated by `scripts/update_stats.py` using Python 3's
standard library and GitHub's API. It is stored in this repository, so the
profile does not depend on a third-party statistics-card server. The generator
updates the README image URL version when the card changes to refresh GitHub's
cached image.

The workflow runs hourly at minute 23 UTC (minute 23 WIB), when its source changes, or
manually from **Actions → Update profile statistics → Run workflow**. GitHub
may delay scheduled runs and disables scheduled workflows in public repositories
after 60 days without repository activity. Re-enable the workflow if necessary.

The workflow uses the built-in `GITHUB_TOKEN`; no personal access token or extra
secret is required. For a local refresh, authenticate with `gh auth login` and
run `python scripts/update_stats.py`, or supply `GH_TOKEN` in the environment.

The card uses GitHub's contribution calendar total and the first date in that
calendar. Technology icons use skillicons.dev.
