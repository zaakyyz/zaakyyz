# Profile maintenance

Edit `README.md` to change the introduction or technologies.
The custom header lives in `assets/banner.svg`.

The contribution card, language chart, and activity calendar are generated by
`scripts/update_stats.py` using Python 3's standard library and GitHub's API.
They are stored in this repository, so the profile does not depend on a
third-party statistics-card server. The generator updates README image URL
versions when cards change to refresh GitHub's cached images.

The workflow runs hourly at minute 23 UTC (minute 23 WIB), when its source changes, or
manually from **Actions → Update profile statistics → Run workflow**. GitHub
may delay scheduled runs and disables scheduled workflows in public repositories
after 60 days without repository activity. Re-enable the workflow if necessary.

The workflow uses the built-in `GITHUB_TOKEN`; no personal access token or extra
secret is required. For a local refresh, authenticate with `gh auth login` and
run `python scripts/update_stats.py`, or supply `GH_TOKEN` in the environment.

The contribution card uses GitHub's last-year calendar total and account
creation date. Language shares use GitHub's code byte counts from public,
non-fork repositories, excluding this profile. The activity calendar uses
GitHub's visible activity.
Technology icons use skillicons.dev.
